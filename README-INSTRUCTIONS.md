# How to apply this update

1. Copy `app/page.tsx`, `app/layout.tsx`, `app/globals.css` from this folder into your
   `RiddheshMore/portfolio` repo, replacing the existing files at the same paths.
2. Copy `public/profile.jpg` into your repo's `public/` folder.
3. `npm install && npm run dev` to preview, then commit + push.
